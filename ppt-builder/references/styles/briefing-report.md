# 风格预设:汇报风格(管理评审型)

`briefing-report` —— 面向领导/评委的管理评审型汇报稿。结论先行、商务留白、克制 Bento。本文件只规定本风格特有的受众、页型、密度、布局偏好与视觉;**Bento Grid 布局规则以 `svg-page-prompt.md` 共享为准**,不重复定义。

## 适用场景

- 项目评审 / 阶段汇报 / 述职 / 答辩(管理导向)
- 受众:领导、评委、导师(决策视角)

## 核心基调

- **结论先行**:每页第一眼是核心结论,再给依据。
- **商务留白**:少卡片、大字号、充足留白,不堆信息。
- **克制装饰**:不用渐变/阴影/复杂滤镜,靠对齐与层级说话。

## 受众与密度

- 受众:领导 / 评委 / 导师
- 信息密度:每页 1 核心结论 + 2–3 支撑卡
- 正文 ≥ ~120 字,拆成卡片,不得文字墙
- 关键数字/结论放大字号

## 推荐页型序列

封面 → 结论先行(总览) → 目录 → 分章节(每章:结论页 + 依据页) → 风险/取舍 → 下一步/请求 → 致谢/Q&A

## Bento 布局偏好(在共享规则内选用)

优先使用以下组合,避免高密度混合网格:

- **单一焦点**:1 张大卡承载核心结论(首页/结论页)。
- **两栏对称(50/50)**:结论 vs 依据、现状 vs 目标。
- **非对称两栏(2/3 + 1/3)**:主内容 + 辅助数据/指标卡。
- **顶部英雄式**:顶部宽幅结论条,下方 2–3 个支撑要点卡。

避免:三栏等宽、密集混合网格(留给技术风格)。

## 配色与视觉倾向

- 主色:商务深蓝 / 灰 / 品牌色,低饱和。
- 背景:白或极浅灰。
- 文字:深灰为主,关键结论用主色或加粗。
- 图表:少而精,优先大数字卡 + 简单条/柱,不做复杂可视化。
- 不用:渐变背景、阴影堆叠、装饰性图标墙。

## 充实度自检

- [ ] 每页有一句可被论证的核心结论?
- [ ] 含核心结论 + 支撑要点/数据 + 证据溯源三要素?
- [ ] 正文 ≥ ~120 字且拆成卡片(无文字墙)?
- [ ] 留白充足、字号层级清晰?
- [ ] 无虚构数据,只用了输入材料?
