# 风格预设:技术风格(工程评审型)v2

`technical-deepdive` —— 面向架构师/同行/技术评委的工程评审技术稿。**视觉骨架沿用信息可视化三段几何**(标题竖条 + 主体卡 + 总结条),**内容基调是方案+权衡**,并新增「实测证据页型」(真实图片 + 数据图表混排)。

> v2 校准记录(2026-09-04,用户风格样本反馈):deck_c(三段骨架视觉)的观感被确认为「技术风格」的正确基调;deck_b 第 3 页(真实实测条带图 + SVG 条形图混排)的页型并入本风格。视觉规范与 `infoviz.md` 共享同一套三段几何与调色板,但两者定位不同(见文末「与 infoviz 的分工」)。

## 适用场景

- 架构评审 / 方案评审 / 技术评审 / 实测成果汇报(工程导向)
- 受众:架构师、同行工程师、技术评委、科研导师

## 核心基调

- **方案+权衡**:不只讲"是什么",更讲"为什么这样选 / 替代方案 / 代价"。
- **图驱动 + 实证驱动**:架构图、对比矩阵、代码卡、真实实测截图/条带图优先于纯文字。
- **信息密集可读**:密集但靠三段骨架与模块卡分块保持可读,不堆文字墙。

## 固定三段骨架(与 infoviz 共享,像素坐标直接套用)

1. **标题区 y0–92**:左侧 6×40 深蓝竖条 `rx=3` + 24px 粗体标题;右上角 13px 灰字 `单位 · 标题 · P页/总页`;`y=92` 一条 `#D8DEE6` 1px 分隔线。
2. **主体区 y100–624**:模块卡(`rx=10`、`stroke="#D8DEE6"` 白底,或深蓝 `#1B3A6B` 强调卡)。
3. **总结强化区 y628–700**:`#EEF3FA` 圆角条 + 左侧 4×40 深蓝竖条 + 「核心结论」小标 + 16px 结论句,关键短语 `<tspan font-weight="bold" fill="#C0392B">` 红色加粗。

封面与总结页可深蓝 `#1B3A6B` 铺底 + 白字,弱化三段。

## 配色 token(与 infoviz 共享调色板,3 色克制)

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 深蓝 | `#1B3A6B` | 标题、卡头、深色强调卡底、流程主节点 |
| 辅色 钢蓝 | `#2E6FB0` | 次级模块、技术图次框、连接线辅色 |
| 浅蓝填充 | `#DCE6F2` | 技术图块底、卡内小框 |
| 强调红 | `#C0392B` | 关键词红字、箭头、重点指标、总结条关键词 |
| 正文深/灰 | `#1F2A37` / `#5A6675` | 正文 / 次要说明 |
| 卡边框 | `#D8DEE6` | 卡 `rx=10` 边框 1px |
| 总结条底 | `#EEF3FA` | 结论强化区底 |
| 代码卡底 | `#26323E` | 等宽字体深色卡,代码用 `#E8A33D`/`#DCE6F2` |

字体栈 `Microsoft YaHei, SimHei, Arial`,根 `<svg>` 统一设;代码/公式用 `Consolas, Courier New, Arial` 独立设。

## 受众与密度

- 信息密度:每页 1 核心结论(技术判断)+ 架构图/对比/证据 + 权衡说明
- 正文 ≥ ~200 字,拆成卡片
- 含数据/指标/取舍依据;不得虚构,全部数字可溯源

## 推荐页型序列

封面(深蓝铺底+抽象主视觉) → 现状/问题 → 实测流程与口径 → **实测证据页**(本风格标志页型) → 方案对比矩阵 → 架构与部署(分层图 + 代码卡) → 风险与演进 → 总结(深蓝铺底+四阶段路线)

## 实测证据页型(v2 新增,核心差异化)

本风格的标志性页型,用于呈现"实测数据 + 实测输出"双重证据:

1. **上半区:SVG 原生数据图**——条形图/指标卡承载核心数字(坐标用 `svg_position_calculator.py` 预计算,遵守文字宽度预算)。
2. **下半区:真实图片嵌入**——`<image href="../assets/xxx.jpg">` 等比嵌入(`preserveAspectRatio="xMidYMid meet"`),宽度 ≤1140 居中;图上方 13px 粗体图注,注明"左→右"各列含义与数据口径。
3. 图片必须有**来源标注**(报告路径/实验口径);无真实图时降级为 B 类占位框(infoviz 四件套),留 `IMAGE_SLOT` 注释。
4. 支线/口径不同的对照数据放独立小卡,标明"口径不同,不可直接比较"。

## 布局偏好(在三段骨架内选用)

- **单一焦点**:大卡放完整架构图(w≈1200)。
- **混合网格**:中等方块(架构层)+ 小水平矩形(指标)+ 垂直矩形(决策)。
- **对比矩阵**:行×列卡片式表格,表头用深蓝/深灰底白字。
- **主次结合**:居中大图(嵌真实图或架构图),两侧小卡放约束/风险。
- 代码块:深色卡(`#26323E`)+ 等宽字体,一行一条,关键行用琥珀/红高亮。

## A 类技术图与 B 类占位

规范与 `infoviz.md` 一致:A 类原生 SVG(模块框 + `<line>` + 手绘 `<polygon>` 箭头,禁 marker);B 类四件套占位(轻虚框 + AI 示意 + 底部标签条 + `IMAGE_SLOT` 注释)。本风格中 B 占位主要用于"预留实拍图位",优先用真实图。

## 与 infoviz 的分工

| | technical-deepdive(本风格) | infoviz |
|---|---|---|
| 场景 | 工程评审 / 技术答辩 / 实测汇报 | 军工/政府/集团规划叙事汇报 |
| 内容 | 方案权衡、对比矩阵、代码卡、风险 | 板块路径、场景占位、规划愿景 |
| 图片 | **可嵌真实实测图**(证据页型) | B 类场景占位为主,不嵌真实图 |
